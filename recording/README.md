# Recording Directory

Place your screen recording `.mp4` file here.

## How to record:
1. Open https://rakeshhostel.github.io/ai-risk-manager/
2. Press Win + Shift + R (Windows 11 Snipping Tool)
3. Record a 30-60 second demo walkthrough
4. Save as `demo.mp4` in this folder
5. Run: `git add recording/ && git commit -m "docs: Add demo recording" && git push origin main`
